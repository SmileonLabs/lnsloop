# Joined Bio 분석 및 LNS Loop 적용 메모

조사일: 2026-09-11

공개 서비스 페이지, 참여자·연구자·파트너 FAQ, 법적 문서 5종, 자료실 3페이지에 공개된 게시물 30건을 검토했다. 공개 가입 화면도 확인했다. 로그인 후 실제 연구 목록·지급·데이터 연결은 테스트하지 않았다. 검색 도구에서 읽히지 않는 페이지는 브라우저에서 확인했다. [페이지별 출처 목록](joined-bio-source-map.md)에 범위를 기록했다.

이 문서의 **관찰**은 사이트가 설명하는 내용이며, 운영 성과·보안·법률 준수를 독립 검증했다는 뜻이 아니다. **해석·제안**은 LNS Loop를 위한 분석이다. [사용자 제공 제품 기준안](../product/lns-loop-product-brief.md)을 변경하거나 새 기능을 확정하는 문서가 아니다.

## 1. 핵심 이해

**Joined Bio는 참여자 네트워크, 의료기록, 검체, 설문, 연구 운영을 연결하는 사업이다.** 참여자에게는 간편한 연구 참여와 보상을, 연구자에게는 조건에 맞는 참여자와 연구 자료의 조달을 제안한다. 기업 고객의 공개 진입점은 견적 요청이다. [참여자 소개](https://joined.bio/participants/), [연구자 소개](https://joined.bio/researchers/), [견적 요청](https://joined.bio/quote-request/)

**LNS Loop에 대한 해석:** 참고 가치가 큰 부분은 의료기록과 일상 기록을 연구에 쓸 수 있게 연결하는 운영 과정이다. LNS Loop는 호주 UC 100명의 12주 참여 경험, 출처 확인, 활동별 정산, 종료 후 결과 요약을 구체적으로 완성하는 방향을 유지하는 것이 적합하다.

| 연구자·기업 | 조건별 모집, 종단 의료기록, 검체·환자 의견, 운영 지원 | 환자·데이터·검체 요구사항을 적어 견적 요청 |
| 커뮤니티 파트너 | 커뮤니티의 연구 참여 확대 및 단체 지원금 | 제휴 신청, 계약, 추천 코드 배포 |

출처: [참여자](https://joined.bio/participants/), [연구자](https://joined.bio/researchers/), [파트너](https://joined.bio/partners/).

**사업모델 해석:** 단순히 가입자 수가 많은 플랫폼보다 연구 수요에 맞는 모집·자료·운영을 납품하는 서비스에 가깝다. 실제 수수료율, 매출, 고객별 가격, 마진은 공개 자료로 확인되지 않았다. 참여자 보상액을 고객 판매가격으로 해석하면 안 된다.

연구자 FAQ는 요구사항·견적 합의 후 구매주문서(PO)로 프로젝트를 시작하고, 회사가 운영을 맡는다고 설명한다. 구매약관은 데이터·검체·관련 서비스의 조달과 사용조건을 다룬다. [연구자 FAQ](https://joined.bio/researcher-faq/), [구매약관](https://joined.bio/purchase-terms/)

## 3. 참여자 경험에서 배울 점

### 공개된 서비스 흐름

무료 가입 → 의료기록 연결 및 자기보고 프로필 → 연구 매칭 → 연구 조건·기간·보상 확인 → 참여 요청·연구별 동의 → 재택 활동 → 진행·보상 확인. 플랫폼 소개는 통합 의료기록 열람, 연구 선호 설정, 참여 현황을 강조한다. 실제 가입 진입 화면에는 Google·Apple·이메일 선택지가 있다. [플랫폼](https://joined.bio/platform/), [가입 화면](https://my.joined.bio/signup)

참여자 페이지는 검체 최대 $250, 설문 $10~$50, 평균 보상 $100을 홍보한다. 이 금액은 활동·연구별 조건이 있는 사이트 표시이며, 모든 참여자의 지급 보장이나 LNS Loop의 A$100 가설과 동등한 단위가 아니다. [참여자 소개](https://joined.bio/participants/)

### 2026년 기능 변화

4월 29일 공지는 연결된 여러 의료기관의 기록을 한곳에서 보는 기능과, 연결 여부와 무관하게 약·보충제·알레르기·가족력 등을 직접 보완하는 기능을 발표했다. [기능 발표](https://joined.bio/news/new-platform-capabilities-that-put-participants-in-control-of-their-complete-health-picture/)

**LNS Loop 제안:** “내 이야기”는 입력 요청만 모아놓는 화면보다, 참여자에게 연결된 기록과 자신의 증상 변화를 되돌려주는 화면으로 설계할 가치가 있다. 병원기록과 본인 입력은 함께 보여주되 출처·날짜·확인 상태를 유지한다.

### 의료기록 연결 실패도 기본 흐름이다

6월 2일 지원 글은 의료기관 검색 시 의사 이름과 의료시스템 이름이 다른 문제, 환자 포털 인증 문제, 연결 후 데이터 로딩 오류를 구분한다. 대안으로 수동 프로필 입력, 지원팀 문의, 이메일 문서 제출을 안내하며 당시 셀프 업로드는 개발 중이라고 적었다. [연결 문제 안내](https://joined.bio/news/having-trouble-connecting-your-health-records/)

**LNS Loop 제안:** 첫 프로토타입부터 `기관 없음`, `인증 실패`, `일부 수신`, `문서 검토 중`, `추가 자료 필요`를 구분한다. 원래 기획에 있는 앱 내 문서 업로드를 대안 경로로 유지하고, 지원팀에 넘어갈 때 기관·시각·오류 식별자를 남긴다. Joined Bio의 이메일 의료문서 수신 방식을 그대로 채택할 필요는 없다.

## 4. 연구자에게 파는 실질적 가치

연구자 페이지는 검체, 실제 의료기록 기반 종단 데이터, 설문·인터뷰를 묶어 제공한다. 적합성 확인은 EMR·AI에 추가 설문·전화·검체 검사를 보완할 수 있다고 설명한다. [연구자 소개](https://joined.bio/researchers/), [연구자 FAQ](https://joined.bio/researcher-faq/)

건강 데이터 소개는 인구통계, 활력징후, 질환, 치료, 검사, 개인·가족력의 범주와 다기관·지속 업데이트를 강조한다. 공개 페이지에서 확인한 것은 제공 범주이며 API 스키마나 특정 병원 연결 목록은 아니다. [건강 데이터](https://joined.bio/health-data/)

검체 상품에는 재택 채취와 임상기관 채취의 구분, 표준 절차, 맞춤 처리, 냉장·냉동 운송이 포함된다. **해석:** 재택 검체 기능은 앱 화면 외에도 채취·보관·물류·품질 책임이 큰 운영 상품이다. LNS Loop의 검체 후순위 계획에 부합하는 참고다. [검체](https://joined.bio/biospecimens/)

**LNS Loop 연구 상품 제안:** 첫 구매 고객에게는 “데이터 플랫폼”이라는 넓은 약속보다 다음 납품 범위를 제시하는 편이 구체적이다.

- UC 참여자 선정 기준과 확인 가능한 기록 범위
- 12주간 제공할 변수·기록 주기·데이터 사전
- 출처·누락·지연·검수 상태를 포함한 품질 보고
- 동의 범위와 승인된 분석 목적
- 연구 일정, 참여 유지 현황, 보상 정산 결과

이는 영업·프로토콜 설계를 위한 제안이며, 검증된 참여자-주의 정의나 단가를 확정한 것은 아니다.

## 5. 개인정보와 동의: 홍보 문구보다 구체적인 문서를 읽어야 한다

### 문서 역할을 나눈다

이용약관은 연구 탐색, 건강정보를 통한 매칭, 실제 연구 참여를 구분하고, 매칭용 건강정보 동의와 연구별 동의를 별도로 설명한다. 개인정보처리방침은 일반 개인정보를 다루며 건강정보에는 별도 동의서가 우선한다고 명시한다. [이용약관](https://joined.bio/terms-of-use/), [개인정보처리방침](https://joined.bio/privacy-policy/)

**LNS Loop 제안:** 계정 이용, 기록 수집·연결, 개별 연구 참여, 선택적 연락을 구분해 이해시키고 동의 버전·시각·범위를 남긴다. 모든 것을 하나의 가입 체크박스로 합치지 않는다.

### 철회는 한 가지 동작이 아니다

건강정보 동의서의 설명은 다음과 같다.

| 행동 | 사이트 문서의 처리 설명 |
| --- | --- |
| 신규 수집 허가 철회 | 새 의료정보 수집 중단. 기존 자료는 남아 매칭에 사용될 수 있음 |
| 연구 선호 변경 | 매칭·연락받을 연구 유형 조정 |
| 건강정보 삭제 | 연구에 사용된 자료 등에 보존 예외가 있음 |
| 계정 삭제 | 계정 종료와 함께 법률·보안·정산 등 보존 예외 적용 |

동의서는 이미 연구에 공유된 비식별 정보의 회수·삭제 한계도 설명한다. [건강정보 동의서](https://joined.bio/health-data-consent/)

**LNS Loop 제안:** 철회 화면은 앞으로 멈추는 일, 기존 데이터 처리, 유지되는 완료 활동 보상, 문의 경로를 함께 보여준다. Joined Bio의 보존기간이나 기본 매칭 설정을 호주 UC 연구 정책으로 복사하지 않는다.

### 보안 표현을 정확히 해석한다

보안 소개는 신원과 건강정보 분리, 코드 부여, 암호화, 역할별 접근통제를 설명한다. 품질 페이지의 표현은 ISO 9001에 맞춘 절차이며 인증서 확인과 동일하지 않다. 건강정보 동의서는 데이터 플랫폼 역할에서 HIPAA 적용대상 기관이 아니라고 명시하면서 HIPAA 수준의 보호를 약속하고, 재식별 위험도 남는다고 설명한다. [보안 소개](https://joined.bio/privacy-and-security/), [품질](https://joined.bio/quality-and-compliance/), [건강정보 동의서](https://joined.bio/health-data-consent/)

**해석:** “100% 준수”, “식별 불가능” 같은 홍보 문구를 외부 인증·위험 제로로 인용하지 않는다. 공개 설명만으로 구현 수준이나 호주 적용 가능성을 판단할 수 없다.

### 구매 고객의 이용 제한도 제품의 일부다

구매약관은 허용 목적, 재식별·직접 연락 제한, 제3자 이전 조건, 검수·거절 절차와 납품 기준을 다룬다. **LNS Loop 제안:** 연구자 접근 승인뿐 아니라 받은 자료를 어디까지 사용할 수 있는지, 납품 품질을 어떻게 판정할지 문서화한다. Joined Bio 약관의 영구적 데이터 라이선스를 LNS Loop의 기본 권리로 채택하지 않는다. [구매약관](https://joined.bio/purchase-terms/)

## 6. 성장 구조와 보상의 차이

개인 추천 프로그램은 공개 공지에서 $10을 안내하고, 최신 약관은 가입·EMR 공유·30일 유지 등 적격 조건과 전자 기프트카드 지급을 명시한다. 개인 추천 보상과 연구 참여 보상은 별개다. [추천 공지](https://joined.bio/news/joined-bio-launches-its-referral-program-expanding-access-and-earnings-for-its-participants/), [추천 약관](https://joined.bio/referral-program-terms/)

파트너 프로그램은 환자단체·인플루언서·지원그룹 등 커뮤니티 채널을 활용한다. 소개 페이지는 가입·정보 공유에 $10, 추천 참여자의 검체 연구 참여에 $50의 단체 지원금을 안내한다. 실제 계약 조건은 별도로 정한다고 설명한다. [파트너 소개](https://joined.bio/partners/), [파트너 FAQ](https://joined.bio/partners-faq/)

**LNS Loop 제안:** 환자단체와의 이해도 검증·교육·자발적 모집 협력은 참고할 수 있다. 개인 또는 기관의 모집 실적당 보상은 현재 기획에 자동 포함하지 않는다. 사용자 기준안은 추천인 모집 기능을 제외한다.

또한 건강 데이터 경제 관련 블로그에는 스마트 계약을 통한 보상 가능성이 언급되지만, 그것만으로 Joined Bio가 토큰·블록체인 지급을 운영한다고 결론 내릴 수 없다. 공개 상품·약관에서 LNS와 같은 토큰 운영은 확인하지 못했다. [데이터 경제 글](https://joined.bio/news/the-billion-dollar-health-data-economy-that-patients-dont-share-in/)

## 10. 사이트 콘텐츠 운영 참고

자료실은 기능 업데이트·연결 문제 해결, 참여자의 권리·보상·접근성, 의료기록·검체의 연구 가치, 회사 인수·유통 채널·인력 발표를 섞어 운영한다. **해석:** 참여자 모집과 기업 신뢰 형성에 서로 다른 콘텐츠가 필요하다는 구조다. 개별 글의 의료·시장 통계는 이번 조사에서 재검증하지 않았으며 사업계획의 근거 수치로 전용하지 않았다. [전체 글 목록](joined-bio-source-map.md)

**LNS Loop 콘텐츠 제안:** “연구 참여는 치료인가요?”, “어떤 기록이 필요한가요?”, “연결이 안 되면 어떻게 하나요?”, “그만두면 기록과 보상은 어떻게 되나요?”, “내 기록이 연구에 어떻게 쓰였나요?”를 첫 도움말 묶음으로 준비한다.

## 11. 추가 확인이 필요한 범위

공개 페이지 검토로 실제 활성 참여자 수, 매칭 정확도, 평균 지급 실적, 데이터 갱신 주기, 병원별 연결 범위, 연구별 계약 가격, 보안 감사 결과는 확인할 수 없었다. 로그인 뒤 제품과 실제 연구 운영도 검증하지 않았다.

자료실·FAQ·상품 문서에는 표현 차이가 있다. 예를 들어 임상시험 모집과 포커스그룹은 페이지별로 현재·미래 설명이 다르고, 직접 EMR 자료의 정확성을 강조하는 문구와 자기보고 기능도 함께 존재한다. 따라서 광고 문구를 현재 기능 전체의 검증된 명세로 간주하지 않는다.
