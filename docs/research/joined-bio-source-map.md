## 범위의 한계

- 공개 메뉴·푸터·자료실을 기준으로 조사했다. 비공개·검색 비노출·연결되지 않은 모든 URL의 전수조사는 아니다.
- 로그인 후 화면, 실제 동의 서명, 기록 연동, 연구 참여, 보상 수령을 실행하지 않았다.
- 외부 소셜미디어, BioSample Connect의 전체 별도 사이트, 외부 연구 논문을 전수 검토하지 않았다.
- 공개 글의 수치·의학·법률 주장을 재검증하거나 보안 인증 실사를 수행한 자료는 아니다.
