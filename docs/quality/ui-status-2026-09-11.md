# UI 구현 현황 — 2026-09-11

현재 앱은 LNS Pulse의 모바일 인터랙션 PoC다. `apps/patient-mobile/app/index.tsx`에서 하나의 Pulse 흐름을 렌더링하며, 앱 전체의 연구 참여 UI는 아직 구현되지 않았다.

| 범위 | 현재 상태 |
| --- | --- |
| 변화 감지 | 신호 리본, 수면·증상·병원 기록 카드, 시작 버튼 |
| 72시간 기록 | 진행 링, DAY 1~3, 기록 작업 목록, 예시 보상 |
| 짧은 설문 | 3개 선택지, 미선택 시 제출 비활성, 선택·제출 |
| 확인 중 | 제출 버튼 비활성, 처리 안내, 자동 다음 단계 |
| 변화 캡슐 | 캡슐 그래픽, 약물 변경 타임라인, 예시 차트·보상, 상세 펼치기 |
| 공통 UI | 뒤로 가기, 다시 시작, 모션/정적 전환, 진행 표시 |
| 실제 연구 UI | 가입·온보딩·동의·적합성·연구 목록·기록 업로드·철회·결과 요약 미구현 |
| 운영 UI | 병원·연구자·운영 관리자 앱 미구현; plan 이미지는 참고 기획 |

검증: 로컬 Expo 웹에서 시작 → 기록 → 설문 선택 → 제출 → 확인 중 → 캡슐 전환, 상세 펼치기, 모션 축소, 다시 시작을 확인했다. TypeScript 검사도 통과했다. iOS/Android 실기기 검증은 이번 점검에 포함하지 않았다.

표시되는 의료기관 확인·웨어러블 연결·시간·보상은 합성 데이터다. 서버·연구 전송·실제 보상 지급을 확인한 것이 아니다.

현재 디자인은 한국어, 어두운 배경, 민트·코랄·보라색의 모션 중심이다. 최신 제품 기준안의 영어 우선, 아이보리 배경, 오늘·연구·내 이야기·보상 탭은 미반영이다. 현재 브라우저 높이에서는 기록·캡슐 하단을 보기 위해 내부 스크롤이 필요하다.
